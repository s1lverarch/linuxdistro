// pacman

Add the SilverNebula repository

Follow the three steps in order.

STEP 1

Import and verify the key

Download the public key and check its fingerprint before trusting it.

terminal 
curl -fLO https://github.com/s1lverarch/silvernebula/raw/refs/heads/main/silvernebula.gpg
gpg --show-keys --with-fingerprint silvernebula.gpg
sudo pacman-key --add silvernebula.gpg
sudo pacman-key --lsign-key 8EA07B2205012BA364DBB14BCC892E251DCD1C44

Fingerprint: 8EA0 7B22 0501 2BA3 64DB B14B CC89 2E25 1DCD 1C44. If it differs, stop.

STEP 2

Add the repository, signed

Append this to /etc/pacman.conf. Packages and the database must be signed.

pacman.conf 
[silvernebula]
SigLevel = Required DatabaseOptional
Server   = https://raw.githubusercontent.com/s1lverarch/silvernebula/main/$arch
STEP 3

Sync and install the keyring

The keyring package keeps the keys updated on later syncs.

terminal 
sudo pacman -Syu
sudo pacman -S silvernebula-keyring
